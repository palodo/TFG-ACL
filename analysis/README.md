# Análisis

Notebooks de análisis que no pertenecen a una sola arquitectura.

- `ACL_Optimized_Pipeline.ipynb` — recorrido del pipeline optimizado de principio a fin.
- `Análisis_Falsos_Negativos.ipynb` — estudio de los falsos negativos comunes a las tres
  arquitecturas en el test de MRNet.
- `prediccion_acl_desde_dicom.ipynb` — predicción a partir de una serie DICOM, paso a paso.

Conservan las salidas de su última ejecución. Para reejecutarlos hacen falta los datos y los pesos
(ver [DATA.md](../DATA.md) y [MODELS.md](../MODELS.md)).
