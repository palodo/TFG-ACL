# Memoria del TFG

Documento del Trabajo de Fin de Grado en LaTeX.

- `tfgs/ejemplo-memoria.tex` — fichero principal; los capítulos están en `tfgs/tex/` y las figuras en
  `tfgs/figs/`.
- `tfgs/ejemplo-memoria.pdf` — PDF compilado.
- `REVISION_TFG.md`, `tfgs/REVISION2_TAREAS.md` — seguimiento de las correcciones de revisión.

Se compila con `tectonic`:

```bash
cd tfgs && tectonic -X compile ejemplo-memoria.tex
```
